## Práticas

### Prática 2/6 - Leitura de Sensor

Aplicação embarcada desenvolvida com **ESP32-S3**, **ESP-IDF** e **Wokwi** para leitura de temperatura e umidade utilizando o sensor **DHT22**.

Objetivo: Desenvolver uma aplicação embarcada completa que leia dados de um sensor simulado no Wokwi e exiba os resultados no monitor serial, utilizando o ESP-IDF dentro do VS Code
